# Security Policy

## Reporting a vulnerability

Open a GitHub issue in this repository for non-sensitive reports. For a sensitive vulnerability, contact the maintainer privately first through the GitHub profile at https://github.com/musichen instead of posting details publicly.

Please say whether the problem is in the catalog data (this README list), the launcher app in `app/`, or the website in `site/`, and include steps to reproduce.

## Notes

Catalog entries link to third-party tools maintained by other people. Review a tool's own repo and install scripts before running it, as the README states: use listed projects at your own discretion.
